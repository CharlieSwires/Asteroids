# Credits

Based on components from Charles Swires' Scramble project at revision
`00ce6fa38f2bfe080e20065fdd30ff55b105aaf3`.

- `InterceptAim.java`: Scramble's expanding-circle intercept solver.
- `SoundEffects.java`: Scramble's Java Sound mixer, with new synthesized sound effects.
- `SaturnExplosion.java`: Charles Swires' original 200-particle Saturn explosion,
  as adapted for Scramble.
- `HighScores.java`: Scramble's ranked top ten and Saturn-compatible score format,
  stored separately by this project.
- The vector shapes, rock splits, movement, collision handling and Swing screens
  were made for this project.

Independent game inspired by Atari's Asteroids. No arcade ROMs, sprites or audio
recordings are included.
